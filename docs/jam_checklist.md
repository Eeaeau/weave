# Weave jam checklist

- [x] Name the Godot project and create a separate local Git repository.
- [x] Establish the first sprite-based 2.5D map, spider, web, collectible, menu, and tooling structure.
- [ ] Review the first scene and project layout in the editor with the team.
- [ ] Agree on match rules, input actions, and the first playable mechanic.
- [ ] Choose an asset license and a code license before inviting contributions or publishing.
- [ ] Replace the icon and shapes with final art, and record all third-party assets in `ATTRIBUTION.md`.
- [ ] Add music to the map's `BackgroundMusic` node and verify audio levels.
- [ ] Check the jam rules for pre-existing templates and assets.
- [ ] Test the exact export target before submission.
- [ ] Configure itch.io repository variables and secret only if using the manual deployment workflow.
